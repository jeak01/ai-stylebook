# 从风格卡生成作品

## 提示词结构

```text
Task: Create one image / Restyle the supplied reference image.
Subject and scene: [the user's actual content]
Preserve: [identity, defining structure, object count, relevant relationships]
Visual treatment: [selected card's rendering_prompt, with relevant signature cues]
Composition: [requested framing and aspect ratio; consistent projection]
Avoid: [selected card's relevant failure modes]
```

如果工具有独立负向提示词字段，可以使用；如果没有，把排除要求写入普通指令。不要假设所有模型支持 seed、负向字段、相同强度参数或相同图像尺寸选项。

## 不同主体的保留要求

| 主体 | 优先保留 | 风格化可改变 |
| --- | --- | --- |
| 人物 | 身份特征、表情、姿态、明确要求的服饰与人数 | 笔触、色块、材料，以及已允许的比例概括 |
| 风景 | 地标、地形、建筑相对位置、前后关系 | 颜色、光线、描绘材料，以及已允许的透视重构 |
| 物品 | 轮廓、部件连接、功能结构、数量、指定文字 | 材料表达、简化程度、照明；需要保留功能形状 |
| 其他 | 用户明确指出的辨识特征 | 与上述要求兼容的视觉处理 |

“保留”不等于逐像素复制。几何、体素、Q 版等风格需要重建形状，重点是身份与结构仍可辨认。用户明确要求固定的内容和机位优先；冲突不能靠悄悄改变内容解决。

## 参考图与新生成

- **参考图转换**：把用户图片作为内容基准。示例总览只用来理解风格，不作为人物身份或场景基准。
- **从文字生成**：使用用户给定的主体和场景。缺少背景时采用简洁、适合主体的背景，并说明必要假设。
- **多风格对照**：固定同一份主体描述、对象数量、构图和比例，再替换风格模块；必要的投影变化单独说明。工具支持时复用相同参考图，不承诺只靠随机种子保证一致。
- **文字与标志**：除非用户要求，不添加文字。用户指定文字应单独写明，不因“招贴”“韩漫”“波普”自动加入标题或气泡。
- **风格标签**：通过可见的造型、线条、材料和光照描述效果，不要求安装与标签同名的软件，不引入现成角色。

## 对应问题的修正

| 问题 | 修正 |
| --- | --- |
| 看起来只有滤镜，主体仍是照片 | 明确要求重建轮廓、边缘和材料；背景也应用同样视觉处理 |
| 三维材料难以辨别 | 分清表面粗糙度、透射、反射、纤维、纸厚或颜料堆积，不增加泛泛“质感” |
| 身份或产品结构改变 | 加强最关键识别特征和部件关系，减弱无关形体夸张 |
| 颜色正确但风格不对 | 检查线条、投影、材质三项，而不是继续堆叠色彩词 |
| 暗色风格看不清 | 恢复关键边缘与中间调，用少量局部光组织画面 |
| 一种风格漂移成另一种 | 读取卡片中的 nearby_styles 与 difference，强化区分特征 |
| 网格对照的主体不一致 | 逐项核对主体描述、参考图与构图约束，重新生成出错的格子 |

生成后至少检查所选卡的三条 signature，结合 avoid 与 tuning 做一次有针对性的修正。工具未返回图片时，只交付提示词，不把提示词描述当成已完成图像。
